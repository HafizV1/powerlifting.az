V2 staging sınağı

Sınaq mövcud GitHub girişinizdən istifadə edir. Bütün nümunələr ayrıca müvəqqəti preview budağında yaradılır. Canlı sayt və adi staging qaralamaları dəyişmir. Bitdikdə sınaq PR-ı bağlanır və budaq silinir; Git tarixçəsi yoxlama üçün qalır.

Sınaq bitənə qədər bu səhifəni açıq saxlayın. Brauzer bağlansa, “Təmizlə” düyməsi ilə qalan sınaq budağını silin.
